# Amazon Homepage

A static Amazon-inspired storefront built with HTML and CSS.

## Files

- `index.html` is the homepage entry point.
- `amazon.html` is the original page.
- `style.css` contains the page styles.
- `amazon.js` is included for JavaScript functionality.
- `first images/` contains the product and promotional images used on the page.
- Root-level image files provide additional page graphics.

## View locally

Open `index.html` in a web browser. No build step is required.
